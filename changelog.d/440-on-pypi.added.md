- **OpenGWASDB is on PyPI: `pip install opengwasdb` (#437, #440).** Every
  release from `v0.11.1` on is published there by `publish.yml` and checked
  after upload by installing it from the index. `docs/install.md` covers
  supported Linux and Python versions, a first run, upgrading and pinning, and
  the separate `bcftools` needed for GWAS-VCF sources.
