- **A `ReaderBatch` now carries each row's `ref` and `alt` as the source spells them, and whoever builds one must pass them (issue #379, ADR 0076).** `opengwasdb.readers.rows.ReaderBatch`, which every Source Reader's `stream_batches` returns, takes two new required arguments, `ref` and `alt`. Each is an object array holding one allele per row, in the batch's row order, with the case and allele order the source writes. A reader that builds its batches through `opengwasdb.readers.rows.stream_batches` gets them from its `SourceRow`s and needs no change. A reader written against v0.5.0 that constructs `ReaderBatch(...)` itself now fails with `TypeError: ... missing 2 required positional arguments: 'ref' and 'alt'` until it passes them, and a batch whose `ref` or `alt` does not hold one allele per row is refused. `build-ragged-ssf` reads them to compare the names a site's spellings carry.
