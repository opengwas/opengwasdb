- **`validate` reports a `completion_n_imputed_total` that is not an integer on an Analysis completed against an ancestry (issue #55).** The count was parsed and checked only on Analyses completed against none. On a completed one, the rule holding the count to the imputed mask could not read it and passed over it, so `analyses.tsv` could carry any text there and still validate, on a Dense, Ragged or Hybrid release alike. Every row's count is now required to be an integer, with the finding the other rows have always had. Every published Store Release's counts are integers, and its `validate` output is unchanged.
