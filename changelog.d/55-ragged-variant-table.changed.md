- **A Ragged release's Store Variant Table is validated as a Dense or Hybrid release's is (issue #55, ADR 0074).** The row count against `variant_offsets.npy`, the row sequence and duplicate canonical variants, the ALID and rsid search indexes, and the offset and tabix spot checks at representative rows ran only on Dense and Hybrid releases; a Ragged release's offset sidecar could point a lookup at the wrong row unremarked. They are now one set of rules for every release. A Ragged `index.sqlite` holds no `variant_aliases` table, so the alias rule is recorded as skipped there, not as passed. Every published Ragged Store Release (OGS-00001, -00002, -00006, -00007 and -00027) passes these rules, and its `validate` output is unchanged.
