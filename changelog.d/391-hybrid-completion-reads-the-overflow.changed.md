- **Hybrid Reference Completion reads its source's Ragged Overflow through the Association Reader (issue #391, ADR 0070).** It read the Overflow's private `offsets` and `variant_index` arrays and decoded `z`, `se` and `eaf` whole; it now reads `CsrReader.windows()` into the same columns, a window at a time, so the presence rule judges every cell it carries. A source cell with one of z and SE missing is still refused, now by the reader with `InvalidAssociations` naming the Overflow, where `require_paired` raised `NotAdmitted`. The Hybrid builder's table writer is public as `write_variant_table`, so completion imports no private name. Completed Stores are unchanged.
