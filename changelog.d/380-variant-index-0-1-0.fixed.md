- **`validate` no longer fails a format 0.1.0 Ragged component for lacking the variant-centric index (issue #380).** Spec §11.1 requires `ragged/by_variant/` only in `format_version` 0.2.0. The rule required it in every format, so OGS-00004, -00005 and -00007, published 0.1.0 releases built before the index existed, failed `validate` for a group their format never had. The index's absence from a 0.1.0 component is now recorded as a skipped rule, with that reason, not as a pass. A 0.1.0 component that carries the index is still checked against its sequence. A manifest that records an index the release does not carry still fails, in any format.
