- **A Hybrid Observed-View Check lets completion drop a shared-axis variant that no Analysis observes, and lists it (stores#478).** OGS-00011's completion left out 668 rows of its 47,920,778-row shared axis. Each was a SNV that no association in the Observed-Only release sits on, yet the check failed on `overflow.parent_rows_unmapped` before it compared a single association. Such a row now counts as dropped. Its count stays in `components.overflow.axis.parent_rows_unmapped`, and the first 1,000 are named in the new `dropped_alids`. The full comparison then runs. A source association on a dropped row fails it, under the new `components.overflow.all_analyses.associations_on_dropped_rows`. An unmapped Dense row still fails as before.
