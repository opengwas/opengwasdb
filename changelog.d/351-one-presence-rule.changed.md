- **Every layout's queries decide whether an association is present by one rule, and read through one module (issue #351, ADR 0070).** An association is present exactly when neither its Z nor its SE carries its plane's missing marker (spec §15); an infinite SE is a value. Dense `analysis()`, `phewas()`, `range_phewas()` and `lookup()` used to drop a cell whose SE was stored `+inf` (an SE above `float16`'s range, #338), and Ragged, Hybrid Overflow and Dense `top_hits()` labelled it `missing`; every layout now returns it `observed` (or `imputed`) with `se = inf`. On the published Store Releases this touches eight cells, all in OGS-00011: four Dense Component cells that now appear and four Overflow cells that change from `missing` to `observed`. A cell spec §15 forbids — one marker without the other, an imputed flag other than 0 or 1, a flag on a missing cell, or a NaN marker other than `np.nan`'s own bits — now raises `InvalidAssociations` naming the component and the first cells, where Dense dropped it and Ragged read it as missing; no published release holds one (every published `float16` SE plane was checked). A Reference-Completed release whose imputed mask is missing is refused when opened, rather than read as all-observed, and a Ragged Top-Hit tier without its own `imputed` array takes the flags from the sequence instead of calling every hit observed. Query methods return an `opengwasdb.associations.Associations` record instead of a `dict`: it reads as the same mapping, with the same keys and dtypes, but cannot be mutated and is not a `dict` instance. `lookup()` is now Analysis-major on Dense and Hybrid, as it was on Ragged: rows come grouped by Analysis in the order requested. `validate` applies the same rule: it now fails a lone marker on an Observed-Only Ragged release or a Hybrid Overflow (it checked completed releases only), a missing Z beside `+inf`, and a non-canonical marker, and passes an imputed cell with an infinite SE with a warning; every published release validates as before. ADR 0033 §7 and §8 are superseded.
