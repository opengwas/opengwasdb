A query that a search index can answer no longer opens the 0.2.x Variant Table or `index.sqlite`. The tabix handle and the `variant_aliases` connection open on first use, and an ALID or rsid in the sidecar indexes resolves to its row without a table read (`VariantAxis.index_of`, `alid_of`). Only a long ALID, `range_phewas`, `variants_table()`, resolved rows with variant info, and an rsid missing from the rsid index still open them. `pysam` and `sqlite3` are no longer imported by `open_store`. Measured on OGS-00009 and OGS-00007, the random-lookup and phewas times do not change (within run-to-run noise); the saving is the file handles and the imports, not query time.
