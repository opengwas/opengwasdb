- **A lift collision drops every source it reaches and records each (issue #325, ADR 0072).** Two source loci that a lift put on one ALID were stored as one variant: the later source's statistics under the earlier one's rsID, a blank `source_alid`, and an empty query result nowhere. OGS-00009 held 8 such rows. Now `place_sites` (the placement Dense, Hybrid and Ragged SSF all call) drops every source variant of an ALID that two or more source loci reach, in either strand; one locus's two allele orders are still one variant, and a GRCh38 source's own variant at that ALID is kept. Each row of a dropped source is logged and counted per Analysis as `lift_collision` (Admission rules `admission/15`), and `lift_collisions.tsv` beside the record names each dropped source with its ALID and rsID. `place_sites` refuses (`ValueError`) to return a lifted group with two loci on one ALID. A Variant Reference frozen before this change is not re-checked. Hybrid checkpoint format 6: a format-5 checkpoint is refused and the build starts again. Releases built before this change may still hold such ALIDs; there is no Store-side `validate` rule, because a Store cannot say which sources were dropped.
