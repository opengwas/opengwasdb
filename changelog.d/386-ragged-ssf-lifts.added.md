- **`build-ragged-ssf` lifts a source that declares a build other than GRCh38 (issue #386).** A GRCh37 (hg19) manifest row was refused; it is now lifted to GRCh38 by the new `--chain-file`, which any such row requires and which is refused before any source is read when it is missing. A row that declares no build is still refused. The lift fails the build when more than `--liftover-failure-threshold` (default 0.01) of the lifted sites have no place on the chain. A reverse-strand chain block re-orients a row's z and frequency, as it does in the other layouts. The Admission record counts what the lift drops, per Analysis, as `lift_unmapped` and `lift_ambiguous` (a Routing Key that a GRCh38 source and a lifted source both declare, dropped from both); the rule set's version is `admission/11`, and a record without the new reasons reads as before. A lifted Store records `provenance.lift`, as `build-ragged-besd` does. A build with a source to lift holds every Analysis's admitted rows in memory until the lift has placed them; a build whose sources are all GRCh38 streams as before and is unchanged byte for byte.
