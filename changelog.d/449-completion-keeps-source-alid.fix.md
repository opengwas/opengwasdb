- **Reference Completion keeps each observed row's `source_alid`, and the validator refuses a lifted release with none (issue #449).** Dense and Ragged completion rewrote the Store Variant Table without the pre-liftover ALID the build recorded, so a completed release lost which source variant any row came from (OGS-00009: `.` on all 11,191,070 rows) and nothing failed. Observed rows now keep their source's `source_alid`; rows added from the panel stay `.`, and a row the build left blank stays blank. The new rule `variant_table.source_alid` fails a release whose manifest records a liftover (`provenance.chain_file` or `provenance.lift`) and whose table holds no `source_alid` at all, on every `format_version`.
