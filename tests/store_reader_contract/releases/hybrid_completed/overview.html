Files in this Store Release, generated at build time. "human" files are safe to open directly; "internal" files are read by the query API and should not be edited by hand.

analyses.tsvhumanAnalytical Metadata -- the source of truth for the Analyses tab. Plain tab-delimited text.
data.zarrinternalAssociation statistics (Z/SE) and top-hit indexes, chunked and compressed. Read via the query API.
denseinternalDense Component -- a nested Dense store holding the Hybrid layout's reference-panel grid. From format 0.3.0 it has its own manifest.json but no variant table or analyses.tsv: its variants and Analyses are this release's.
manifest.jsonhumanStore identity, format version, and provenance. Plain JSON.
overview.htmlhumanThis page.
variant_alid_keys.npyinternalSorted ALID search keys (ALID sidecar).
variant_alid_offsets.npyinternalWhere each row's ALID starts (ALID sidecar).
variant_alid_order.npyinternalThe row of each sorted ALID key (ALID sidecar).
variant_alid_utf8.npyinternalEvery variant's ALID, in row order (ALID sidecar).
variant_position.npyinternalEvery variant's position, in row order (position sidecar).
variant_position_chromosome_offsets.npyinternalWhere each chromosome's rows start (position sidecar).
variant_position_chromosomes.npyinternalThe chromosomes the rows are on, in order (position sidecar).
variant_rsid_bytes.npyinternalSorted rsID search keys (rsID index).
variant_rsid_rows.npyinternalThe row of each sorted rsID key (rsID index).
variant_source_alid_offsets.npyinternalWhere each lifted row's pre-liftover ALID starts (source_alid sidecar).
variant_source_alid_state.npyinternalWhether each row has a pre-liftover ALID, and whether it is the row's own (source_alid sidecar).
variant_source_alid_utf8.npyinternalThe pre-liftover ALID of each lifted row (source_alid sidecar).
variants.tsv.gzhumanThe Store Variant Table, one row per variant: tab-delimited, bgzipped and tabix-indexed, for tabix, bedtools and R. From format 0.3.0 no query reads it: queries read the variant sidecars below. A 0.2 release's queries read it.
variants.tsv.gz.tbiinternalTabix index for variants.tsv.gz. From format 0.3.0 no query reads it.
